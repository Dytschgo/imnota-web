Capture

An area, a window or the whole screen.

A global shortcut, the tray or menu-bar icon, or the toolbar. Drag across screens, add a 3 or 5 second delay, repeat the last area, then save, annotate or copy from the capture overlay.

CtrlShift5

Readable marks

Every mark, in words.

Prompt Markdown lists arrows, boxes and steps as positions, with the screenshot's source size. 

### Picture 1 / Marks
- arrow `a1` to 75.9%,83.0%
- rectangle `r1` 19.4%×12.5%
- step `s1` number 1

On-device OCR

The text on screen, too.

Optional text recognition adds a visible-text section. It runs on your device and skips blurred or pixelated screenshots.

Local agent access

No paste. Your agent reads the bundle.

Turn it on in Settings and any MCP-capable coding agent on the same computer can list projects and load your latest prepared bundle. Off by default. Listens only on 127.0.0.1.

Manual build

Clone the source repository and open its folder in your terminal. Use Node.js 22.13+ and Corepack, then run the packaging command for your operating system.

From the Imnota source folder 
corepack enable
corepack pnpm install
corepack pnpm package:win   # Windows
corepack pnpm package:mac   # macOS
corepack pnpm package:linux # Linux

The last three lines are alternatives. Run only the target you need.

A few practical answers.

Does Imnota upload my screenshots?

Local editing, capture, copy and export use files on your machine. Optional Share online uploads only the finalized PNG and Markdown bundle you review and approve, not your editable project folder. Anyone with the link can open it until it expires or you revoke it.

Do I need an AI account to use it?

No. Imnota has no account requirement and no built-in AI provider connection. It prepares context for the assistant or coding agent you already use.

How does local agent access work?

It is off by default. When you turn it on in Settings, Imnota listens only on 127.0.0.1 so an MCP-capable coding agent on the same computer can list projects, read collection items and load the latest bundle you prepared. Agents cannot create exports for you. See the agent guide.

Which operating systems are supported?

Windows, macOS 13 or later, and Linux. Screen capture works on Windows and macOS; on Linux, import or paste screenshots. Check the latest release for available desktop downloads.

What does the export contain?

A fresh, timestamped export in collection order, with Markdown and high-resolution PNGs for visual items. Text-only collections export Markdown without placeholder images. The Markdown includes collection context, screenshot and drawing descriptions, agent priorities, text or callout notes, annotation marks as positions and the source size of each screenshot. Optional on-device text recognition adds visible text. Large collections may split automatically.

Can I build Imnota from source?

Yes. You need Node.js 22.13+, Corepack and a platform-supported Electron environment. Follow the manual build instructions or the development README.

Is Imnota Apple-notarised?

The current release is not Apple-notarised. The README explains how to open it through System Settings, Privacy & Security, Open Anyway. Read the macOS installation guidance. Do not disable Gatekeeper.
