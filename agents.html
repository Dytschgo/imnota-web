Visual context for coding agents

Give the agent
the whole idea.

Imnota turns a screenshot, its annotations and your written explanation into a portable prompt bundle that can be pasted into a coding-agent workflow.

Download ImnotaRead an example bundle ↗

What the agent receives.

The bundle keeps the visual evidence and the instruction together.

  • Annotated PNG showing exactly where to look
  • Markdown context describing the screen and intended change
  • Callout notes and numbered steps
  • Agent priority and collection order
  • Drawing descriptions and standalone Markdown items
  • Arrows, boxes and steps listed as positions
  • The source size of each screenshot
  • Optional on-device visible text

A clear handoff.

Collect screenshots or drawings, mark the important area, describe what should change, then export.

Example Markdown
# Checkout review

## Overall context
Review the interaction details before the next product release.

Priority for agent: High

Make the primary action clear and align it with the form fields.

### Picture 1 / Marks

- arrow `a1` from 53.8%,72.0% to 75.9%,83.0%
- rectangle `r1` at 77.5%,81.0% 19.4%×12.5%
- step `s1` number 1 at 77.5%,81.0%

Use the files your editor accepts.

Give the agent both the image and its matching Markdown.

On Windows, Copy files is the default, with a saved preference for other copy formats. Markdown, image and rich-copy actions are also available. If the receiving editor accepts only one format, use the separate copy actions or attach the generated files.

Imnota reports what the clipboard kept. Check the draft for both the image and the instructions before sending it.

Or let the agent read it.

Optional local agent access, new in 0.3.0. No clipboard paste.

Turn on MCP access in Settings > Features. Choose Copy prompt and paste it into your coding agent. The prompt contains the local server address, a stdio alternative and the tool list, and asks the agent to write its own MCP configuration. Imnota does not edit agent configuration itself.

  • list_projects: active projects in the workspace
  • list_collection_items: ordered items and their priorities
  • get_latest_bundle: the latest prepared Markdown and PNG paths
  • get_item: one item's Markdown and image path
  • search_saved_text: matches in saved text

It is off by default and listens only on 127.0.0.1. Agents read bundles you already prepared with Copy Bundle; they cannot create exports, and backups, recovery files and sharing secrets are not exposed.

Imnota is local-first, open source under the MIT licence and available for Windows, macOS and Linux. Explore all features or inspect the source on GitHub.
