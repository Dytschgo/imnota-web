Visual context for coding agents

Give the agent
the whole idea.

Imnota turns a screenshot, its annotations and your written explanation into a portable prompt bundle that can be pasted into a coding-agent workflow.

Download ImnotaRead an example bundle ↗

What the agent receives.

The bundle keeps the visual evidence and the instruction together.

  • Annotated PNG showing exactly where to look
  • Markdown context describing the screen and intended change
  • Callout notes and numbered steps
  • Agent priority and collection order

A clear handoff.

Collect screenshots or drawings, mark the important area, describe what should change, then export.

Example Markdown
# Checkout review

## Overall context
Review the interaction details before the next product release.

Priority for agent: High

Make the primary action clear and align it with the form fields.

Imnota is local-first, open source under the MIT licence and available for Windows, macOS and Linux. Explore all features or inspect the source on GitHub.
