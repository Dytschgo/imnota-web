0.2.8

Capture, context and a smoother handoff.

Start with a useful brief, capture what needs to change and prepare the files your coding agent needs.

  • Five optional project templates: Bug report, UI review, Feature request, Design-to-code brief and Architecture handoff. Each creates editable Markdown blocks in your collection.
  • Experimental region capture from the toolbar, Add menu or a configurable shortcut. Windows can capture a region within one display or across display boundaries.
  • A screenshot-first Add action and optional drawing descriptions that travel with prompt Markdown.
  • Windows copy preferences, with files as the default and separate Markdown, image and rich-copy options. Combined copy reports which formats the clipboard kept. Open files stays a separate action.
  • Roomier bundle previews, generated-file fallbacks and a guided sample for learning the screenshot-to-prompt workflow.
  • Search across saved descriptions, annotation text, Markdown and drawing text, plus Back and Forward navigation that restores the project, collection and item.
  • Local backup snapshots with validation, archive export and restore options. Automatic history is opt-in and runs before migrations and whole-project deletion.
  • Shortcut recorders show when they are listening, explain conflicts and offer per-row reset and clear controls.
  • Background update checks at startup and about hourly, a download indicator beside About, reachable release notes and What's new guidance. Downloads and installation remain your choice.

Before you update

macOS 13 or later is required. Mac downloads remain ad-hoc signed, not Apple-notarised. Back up your workspace before upgrading.

Capture is experimental and off by default. macOS needs Screen Recording permission; Linux capture is unavailable. Import and paste remain available. The receiving editor decides which clipboard formats it accepts.

0.2.6

Share the handoff. Find your flow.

Optional online sharing joins the local workflow, with browser copy actions and a refreshed desktop workspace.

  • Hosted prompt links with device pairing, expiry and revocation. Recipients can copy a bundle, copy Markdown or PNG separately, and download the ZIP. Sharing settings keep local link history and controls together; site owners get private management.
  • Improved search, project management, collection history and grouped favourites make it easier to return to your work.
  • Reworked navigation and editor headers, annotation tools that adapt to available space, and tooltips that dismiss after selection.
  • Centered dialogs, larger bundle previews, simpler inclusion controls and recoverable item deletion from the collection list, with stale recovery banners and duplicate prompts removed.
  • More readable light themes, restored backdrop transparency, new generic light and dark backgrounds, and matching drawing and screenshot canvas surfaces.
  • Better edit preservation, recovery after interrupted exports, more visible updates and macOS rollback cleanup. Windows saves retry temporary file locks and preserve the committed file if the lock persists.
  • Sharing works on system proxy networks. Versioned sharing-page assets prevent stale cached files from breaking updated pages.

Local by default. Share when ready.

Online sharing uploads the finalized artifacts you approve. Anyone with the link can access them until expiry or revocation; revocation cannot remove copies already saved. Local editing, copy and export remain available offline.

This release keeps the existing project format. Back up your workspace before upgrading. macOS downloads remain ad-hoc signed, not Apple-notarised.

0.2.5

Drawings and Markdown join the collection.

Sketch an idea without a screenshot, give written context its own item and keep all three kinds of content in the order you need.

  • Standalone drawings with essential Excalidraw tools and connectors that stay attached to shapes. Drawings save editable JSON and a cropped PNG with white background and padding.
  • Body-only Markdown items with editing and preview, stored alongside screenshots and drawings.
  • Shared ordering, visibility, duplication and recoverable deletion for all three item types. Drawing and text editors autosave with a saving indicator.
  • Mixed-content exports preserve collection order and include images and written explanations. Text-only collections export Markdown without placeholder images.

Back up before adding drawings or text

Adding either item upgrades the project to schema 4 and preserves a schema 3 backup. Older app versions cannot open the upgraded project. Back up your workspace before upgrading.

0.2.4

Collections, crops and a calmer workspace.

A stable release for Windows, macOS and Linux, with more control over the workspace and the exported handoff.

  • Collection-based PNG prompt bundles with corresponding Markdown, screenshot references and export exclusions.
  • Non-destructive crop controls with Apply, Cancel, Reset and resize handles.
  • Improved annotation selection and resizing, macOS deletion shortcuts and collapsible navigation.
  • Grouped Settings, one app-wide backdrop and a local uploaded-image library.

Before you upgrade

Back up your workspace folders. Older versions may not support newer project data.

Desktop glass is optional and remains Beta. If scrolling or transparency glitches, choose No image or Solid surfaces in Settings.

macOS downloads support Intel and Apple Silicon. They are ad-hoc signed and are not Apple-notarised. See the installation guidance.

There is no downloadable 0.2.3 release. macOS release checks caught temporary test-path issues; 0.2.4 corrects those fixtures, and PR checks now run unit tests on each packaged platform.
