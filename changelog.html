0.2.5

Drawings and Markdown join the collection.

Sketch an idea without a screenshot, give written context its own item and keep all three kinds of content in the order you need.

  • Standalone drawings with essential Excalidraw tools and connectors that stay attached to shapes. Drawings save editable JSON and a cropped PNG with white background and padding.
  • Body-only Markdown items with editing and preview, stored alongside screenshots and drawings.
  • Shared ordering, visibility, duplication and recoverable deletion for all three item types. Drawing and text editors autosave with a saving indicator.
  • Mixed-content exports preserve collection order and include images and written explanations. Text-only collections export Markdown without placeholder images.

Back up before adding drawings or text

Adding either item upgrades the project to schema 4 and preserves a schema 3 backup. Older app versions cannot open the upgraded project. Back up your workspace before upgrading.

0.2.4

Collections, crops and a calmer workspace.

A stable release for Windows, macOS and Linux, with more control over the workspace and the exported handoff.

  • Collection-based PNG prompt bundles with corresponding Markdown, screenshot references and export exclusions.
  • Non-destructive crop controls with Apply, Cancel, Reset and resize handles.
  • Improved annotation selection and resizing, macOS deletion shortcuts and collapsible navigation.
  • Grouped Settings, one app-wide backdrop and a local uploaded-image library.

Before you upgrade

Back up your workspace folders. Older versions may not support newer project data.

Desktop glass is optional and remains Beta. If scrolling or transparency glitches, choose No image or Solid surfaces in Settings.

macOS downloads support Intel and Apple Silicon. They are ad-hoc signed and are not Apple-notarised. See the installation guidance.

There is no downloadable 0.2.3 release. macOS release checks caught temporary test-path issues; 0.2.4 corrects those fixtures, and PR checks now run unit tests on each packaged platform.

0.2.2

A clearer path to the next update.

  • macOS Terminal update action and copyable command, with verified downloads, graceful shutdown, rollback and retained app backups.
  • Update progress, save-before-restart protection and retryable installation errors.
  • Refreshed Settings and subfolder creation, fixed project search and repositioned navigation controls.
  • Nightly subscribers can receive a newer stable release while retaining their preview-channel preference.

Portable Windows and Linux .deb packages retain their supported manual installation paths.
